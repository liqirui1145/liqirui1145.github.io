这里是我的技术笔记。

平时主要在 Linux 上折腾：系统配置、shell 脚本、时间同步，以及各种"明明改了配置却没生效"的问题。写下来的原则只有一条——**能复现的才写，写完自己再跑一遍**。

## 关于这个站

- 静态生成：[Hugo](https://gohugo.io/)
- 托管：[GitHub Pages](https://pages.github.com/)
- 评论：giscus（基于 GitHub Discussions），不额外收集访客信息
- 无追踪、无广告
- 全文 RSS：[/index.xml](/index.xml)

## Colophon

- 字体：正文用系统中文宋体栈（Noto Serif CJK SC / Songti SC / SimSun），界面用微软雅黑 / PingFang SC；代码用 Cascadia Mono / Consolas。没有加载外部字体。
- 编辑：VS Code 写 Markdown，图片交给 Hugo 的图片处理生成 WebP 和 srcset。
- 构建：Hugo 0.170 + Dart Sass；push 到 `main` 后由 GitHub Actions 构建并部署到 GitHub Pages。
- 排版：正文 17px、行高 1.8，中文约 36–38 字/行；标题靠字重和留白分层；引用和代码只用一条细线，不做圆角卡片。
- 为什么：这是博客，不是产品落地页。少一点装饰，读起来更像纸。
