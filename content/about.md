我是 liqirui。平常在 Linux 上折腾系统配置、shell 脚本和时间同步，也顺手记下同学和瓜。

这个站没有推荐算法，也不追热点。写下来的原则只有一条：**能复现的才写，写完自己再跑一遍**。

## 这个站

用 Hugo 生成，托管在 GitHub Pages；评论走 giscus，不额外收集访客信息。没有追踪，没有广告。全文 RSS 在 [/index.xml](/index.xml)。

## Colophon

- 字体：正文用系统中文宋体栈（Noto Serif CJK SC / Songti SC / SimSun），界面用微软雅黑 / PingFang SC；代码用 Cascadia Mono / Consolas。没有加载外部字体。
- 编辑：VS Code 写 Markdown，图片交给 Hugo 的图片处理生成 WebP 和 srcset。
- 构建：Hugo 0.170；push 到 `main` 后由 GitHub Actions 构建并部署到 GitHub Pages。
- 排版：正文 17px、行高 1.8，中文约 36–38 字/行；标题靠字重和留白分层；引用和代码只用一条细线，不做圆角卡片。
- 为什么：这是博客，不是产品落地页。少一点装饰，读起来更像纸。
